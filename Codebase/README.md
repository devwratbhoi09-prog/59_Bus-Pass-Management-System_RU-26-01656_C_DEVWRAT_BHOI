Bus Pass Management System

Project Name: Bus Pass Management System
Problem Statement Number: 59
Language: Python 3
Project Type: Mini Project

1. Introduction

The Bus Pass Management System is a Python-based project designed to manage bus pass registration and records. It helps users apply for different types of bus passes easily.

2. Objectives

- To manage bus pass registration.
- To store passenger information.
- To provide different types of bus passes.
- To calculate bus pass fees.
- To maintain records using file handling.

3. Technologies Used

- Python 3
- File Handling
- VS Code

4. Pass Types and Fees

Pass Type| Duration| Fees
Monthly| 30 Days| ₹500
Quarterly| 90 Days| ₹1350
Yearly| 365 Days| ₹4800

5. Features

- New bus pass registration.
- Different pass categories.
- Automatic fee calculation.
- Data storage using a text file.
- Simple and user-friendly interface.

6. Project Files

- Python source code
- buspass.txt – Stores bus pass records.

7. How to Run

1. Install Python 3.
2. Open the project in VS Code.
3. Run the Python program.
4. Follow the instructions displayed on the screen.

8. Conclusion

The Bus Pass Management System makes bus pass management easier and helps maintain passenger records efficiently.
